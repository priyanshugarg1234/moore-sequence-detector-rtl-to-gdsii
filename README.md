# Moore Sequence Detector – RTL to GDSII

## 📌 Project Overview

This project demonstrates the complete **RTL-to-GDSII implementation** of a **Moore Sequence Detector** using **Verilog HDL** and **Cadence Innovus**. The design flow includes synthesis, floorplanning, placement, clock tree synthesis, routing, timing analysis, area analysis, and power analysis.

---

## 🚀 Design Flow

* RTL Design using Verilog HDL
* Logic Synthesis
* Floorplanning
* Placement
* Clock Tree Synthesis (CTS)
* Routing
* Timing Analysis
* Power Analysis
* Area Analysis

---

## 🛠 Tools Used

* Verilog HDL
* Cadence Genus
* Cadence Innovus
* Linux Environment
